# qmc5883p —— 磁力计驱动

## 职责

管好手背上那颗 QMC5883P：

- 初始化并配置量程、输出速率
- 读三轴磁场，换算成微特斯拉
- 把芯片的轴向转到与 QMI8658A 一致的机体系

只有手掌那颗 IMU 走 9D，所以这个驱动只服务一个融合实例。

## 依赖

- `board`：I2C 总线
- 不依赖其它驱动

## 对外接口

```c
esp_err_t qmc_init(void);
esp_err_t qmc_read(vec3_t *mag_ut);       /* 无新数据返回 ESP_ERR_NOT_FOUND */
esp_err_t qmc_read_chip_id(uint8_t *id);
```

地址 0x2C，走 I2C 400kHz。

## 验收（P0）

- 读 `CHIP_ID` 返回 `0x80`
- 静止时三轴读数在 20 到 80 微特斯拉之间（地磁场典型 25 到 65）
- 手掌水平缓慢转一圈，磁场矢量在世界系里基本不动

第三条是判断轴向有没有转对的依据。

## 当前实现架构

### 简介

上电读一次 ID 确认通信，配好量程和速率，之后按需读六个字节。

### 寄存器

| 名称 | 地址 | 用途 |
|---|---|---|
| CHIP_ID | 0x00 | 固定 `0x80` |
| X_LSB 到 Z_MSB | 0x01 到 0x06 | 三轴数据，小端 |
| STATUS | 0x09 | bit0 是新数据标志 |
| CNTL1 | 0x0A | 模式、过采样、输出速率 |
| CNTL2 | 0x0B | 量程、自检、软复位 |

CNTL1 配 `0x37`：连续测量、8 倍过采样、50Hz。

50Hz 够用。融合层的磁力计更新是 100Hz，但磁力计本身只在有数据时才更新，读快了只是多花 I2C。

### 量程与灵敏度

CNTL2 配 `0x0C`，即 RNG 位为 `11`，对应 ±2 高斯量程。

手册 Table 2 给的灵敏度：

| 量程 | 灵敏度 |
|---|---|
| ±30G | 1000 LSB/G |
| ±12G | 2500 LSB/G |
| ±8G | 3750 LSB/G |
| ±2G | 15000 LSB/G |

地磁场约 0.5 高斯，±2G 量程下只用到满量程的四分之一，但分辨率最高，这是选它的理由。

1 高斯等于 100 微特斯拉，所以 15000 LSB/G 即 **150 LSB/µT**。

### 轴向换算

QMC5883P 的坐标定义（手册 Figure 2）与 QMI8658A 不同：

| 轴 | QMI8658A | QMC5883P（实测朝向） |
|---|---|---|
| x | 朝后 | 朝右 |
| y | 朝右 | 朝前 |
| z | 朝上 | 朝上 |

两者差一个绕 z 轴的 90 度旋转。两颗芯片同一个元件面朝上焊，实际机体系要统一，所以读出来先转一次：

```
mag.x = -my
mag.y =  mx
mag.z =  mz
```

磁力计的轴以人体自然坐标系描述：手背朝上平举时 x+ 朝右、y+ 朝前、z+ 朝上。这与手册 Figure 2 的图面朝向不同，是 PCB 摆放决定的实际朝向。

换算的前提是 PCB 上磁力计相对 IMU 的位置固定。板子改了摆放，这里要跟着改。

### 磁干扰

驱动不做任何滤波或判断，原样交给 `vqf_update_mag`。干扰检测、降权、参考建立都在 `lib/vqf.c` 里，属于算法层的事。
